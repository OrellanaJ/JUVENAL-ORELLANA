# JUVENAL-ORELLANA ALMENDRAS
1: ACTORES
1. VENDEDOR
Consulta productos disponibles.
Busca productos por categoría.
Registra ventas.
Agrega productos al carrito.
Confirma ventas.
Registra pagos.
Consulta ventas realizadas.
2. ADMINISTRADOR
Registra productos.
Administra productos.
Administra categorías.
Ajusta el stock.
Modifica precios.
Consulta movimientos de stock.
Gestiona alertas de stock mínimo.
Consulta reportes de ventas.
3. CLIENTE
Consulta productos disponibles.
Consulta productos por categoría.
Realiza compras.
Consulta el estado de su venta.
Cancela una compra cuando corresponda.
4. ENCARGADO DE INVENTARIO
Consulta el stock de productos.
Registra entradas de productos.
Registra salidas de productos.
Realiza ajustes de stock.
Consulta movimientos de inventario.
Atiende alertas de stock mínimo.
2: INVENTARIO DE MODULOS
2.1. Gestión de productos

Responsabilidad: Administrar los productos disponibles en la tienda, incluyendo precio, stock actual y stock mínimo.

Funciones principales:

Registrar productos.
Modificar productos.
Consultar productos.
Actualizar precios.
Consultar disponibilidad.
2. GESTION DE CATEGORIA

Responsabilidad: Organizar y clasificar los productos de la tienda.

Funciones principales:

Registrar categorías.
Modificar categorías.
Consultar categorías.
Asociar productos a categorías.
3. GESTION DE VENTA

Responsabilidad: Registrar y administrar las ventas realizadas en la tienda.

Funciones principales:

Crear venta.
Agregar productos al carrito.
Confirmar venta.
Registrar pago.
Entregar venta.
Anular venta.
Consultar ventas.

Estados de una venta:
Carrito → Confirmada → Pagada →

4. GESTION DE INVENTARIO

Responsabilidad: Controlar las entradas, salidas y ajustes de stock de los productos.

Funciones principales:

Registrar entrada de productos.
Registrar salida de productos.
Ajustar stock.
Consultar movimientos.
Actualizar stock disponible.
5. GESTION DE ALERTAS STOCK

Responsabilidad: Informar cuando un producto alcanza o cruza el stock mínimo establecido.

Funciones principales:

Detectar stock mínimo.
Generar alerta.
Consultar alertas.
Marcar alerta como atendida.

6. GESTION DE REPORTES

Responsabilidad: Generar información sobre las ventas y productos comercializados.

Funciones principales:

Consultar ventas por período.
Generar reporte de ventas.
Identificar productos más vendidos.
Consultar productos con bajo stock.


 Atributos críticos

Usabilidad: El sistema debe ser fácil y rápido de utilizar, permitiendo que el vendedor registre ventas, consulte productos y gestione el carrito de manera sencilla.

Portabilidad: El sistema debe poder adaptarse a diferentes dispositivos y plataformas a medida que el negocio crezca.
